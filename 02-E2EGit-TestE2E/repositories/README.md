# Repositories del Progetto

Questa cartella raggruppa in modo modulare i repository software analizzati nel tirocinio.  
Ciascuna repository ha una propria struttura con tre cartelle dedicate:
- `repo/`: clone Git della repository
- `docker/`: ricette Dockerfile e script per l'esecuzione dinamica multi-versione
- `results/`: report Markdown, dataset CSV e log di esecuzione dei test
